## Criterios de elección

- [ ] Idioma compatible con el alcance del proyecto
- [ ] Tamaño suficiente para fine-tuning
- [ ] Etiquetas granulares (no solo binario)
- [ ] Datos de redes sociales incluidos (metadatos, propagación)
- [ ] Disponibilidad pública o por solicitud razonable
- [ ] Licencia compatible con uso académico
