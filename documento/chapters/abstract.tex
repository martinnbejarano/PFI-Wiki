\chapter*{Abstract}

This work addresses the spread of disinformation on social media and the lack of a free tool, adapted to the Argentine context, that allows users to assess the veracity of a post at the moment they read it. To that end, Factum was developed: a Google Chrome extension for X that combines a natural language classifier fine-tuned on Spanish corpora, the public signals of the author's account, and the comparison of the claim against official sources, reference media outlets, and professional fact-checkers. Each result comes with a justification and links to the sources that support it, so that users can verify it on their own. The project was implemented as a functional prototype that integrates into the X timeline, with a web dashboard that gathers each user's analysis history and shows organizations which topics are circulating. On 94 verified Argentine posts, the system's verdict outperformed the baseline and did not flag any true post as false.
